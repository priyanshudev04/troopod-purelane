# Purelane — Shopify Homepage Assignment

Shopify implementation of the Purelane plant-based homecare homepage prototype.

## Focus

The implementation prioritizes the five requested sections:

- Hero
- Shop / product grid
- Best-selling combos
- Bundles
- Reviews rail

Additional homepage areas were also implemented/refined to match the supplied design direction.

## Built with

- Shopify Liquid
- Dawn theme
- HTML
- CSS
- JavaScript
- Shopify product/section/block data

## Key qualities

- Responsive layout
- Merchant-editable section structure
- Shopify-native product presentation
- Reusable card patterns
- Smooth interactions
- Reduced-motion support
- Theme-editor-safe section behavior
- Accessibility-conscious navigation and focus behavior
